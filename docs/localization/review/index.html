How to review / Ako kontrolovať
English
  1. Pick the languages to compare in the bar below (default: English and Slovak). Use the filter for strings that still need review.
  2. Read each string together with Where it is used: it says where the text appears in the app and what the placeholders mean.
  3. This page is read-only. Write corrections in your language's CSV (sk.csv for Slovak): fill the corrected column, optionally note. Write [ok] in corrected to confirm the current text is right; leave it empty to skip the row.
  4. Keep the %@ %lld %1$@ placeholders (highlighted): same type and same count as in English. Rows that break this are rejected on import.
  5. Plural strings have one row per form (one, few, many, other). Translate each form for the number it stands for; the app picks the form from the number.
  6. Save the CSV as CSV UTF-8 (a semicolon separator is fine) and send it back.
Slovensky
  1. V paneli nižšie vyberte jazyky na porovnanie (predvolene English a Slovenčina). Filtrom zobrazíte texty, ktoré ešte čakajú na kontrolu.
  2. Každý text čítajte spolu so stĺpcom Where it is used (kde sa používa): hovorí, kde sa text v aplikácii zobrazí a čo znamenajú zástupné znaky.
  3. Táto stránka je len na čítanie. Opravy píšte do CSV svojho jazyka (sk.csv): vyplňte stĺpec corrected, voliteľne note. Ak je súčasný text správny, napíšte do corrected hodnotu [ok]; prázdne pole znamená, že riadok preskakujete.
  4. Zachovajte zvýraznené zástupné znaky %@ %lld %1$@: rovnaký typ a rovnaký počet ako v angličtine. Riadky, ktoré to porušia, sa pri importe odmietnu.
  5. Množné číslo má riadok pre každý tvar (one, few, many, other). Preložte každý tvar pre číslo, ktoré zastupuje; aplikácia tvar vyberie podľa čísla.
  6. CSV uložte ako CSV UTF-8 (bodkočiarka ako oddeľovač je v poriadku) a pošlite späť.
